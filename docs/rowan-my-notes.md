# My notes

## Assumptions

I made a few assumptions along the way: different needs among different advisors, different roles, purchase cycles & ultimately different products.

**A** is the only one where pain → buyer → price → workflow → “pay now” all line up for a shippable wedge (**C** & **J** echoed this need).

- **B / D / F** — not licensed wealth advisors (different buyer, different product).
- **E / I** — book transitions / succession projects (high $, infrequent, home-office buyers).
- **G / C / H** enterprise angle — content, compliance, or firm-wide intel (long sales cycle, advisor can’t buy alone).

**Tradeoff I’m accepting:** narrow wedge now; broaden later only if A-like buyers pay.

### Wrong customer

Some interviews weren’t independent wealth advisors at all — CFO reporting, bank ops, tech brokerage. Good problems, different company. Building for them means abandoning the Rowan advisor thesis.

### Right world, wrong shape

Book transitions and succession can be big money — but they’re rare projects. Home office often buys (or blocks). That’s consulting, not a tool someone buys this month and uses every Monday.

### Real pain, advisor can’t buy

Content, compliance, firm-wide intel — advisors want it, but marketing or the bank owns budget and approval. Year-long sales cycle. I’m not starting a founding wedge there.

## Which Rowan themes this product tackles

**Mainly these two:**

- **Surfacing compliant growth opportunities** — core job. Rank dormant prospects, say why call them, give a talk track, help turn a cold book into meetings.
- **Keeping the advisor in control** — you never auto-email or auto-dial. Human picks, calls, logs, exports. AI recommends; advisor decides.

**Partially / lightly:**

- **Catching follow-through that would otherwise be missed** — only in a narrow sense: a ranked weekly list + outcome log so names don’t die in a spreadsheet. Not full meeting→commitment tracking.

**Mostly not this product:**

- Detecting meaningful changes across clients/prospects (ongoing alerts)
- Moving work safely between people and systems
- Preparing forms, records, and follow-up correctly

## 2. What I built (2 min talk + 3–4 min live)

**Reactivation Desk** — export a messy CSV → finishable weekly call list → polished call tips → log outcomes → next week.

**Live path (use the desk):**

1. Unlock (Sprint / Unlimited or promo).
2. Import a book → AI guesses who you sell to / what you reopen → user corroborates (not Advisor-A-only chips).
3. Build a short week (budget you can finish).
4. Open a name → call polish grounded in the file (+ light public context).
5. Wrap → leftovers / next week.

**Why it’s sellable now:** completes one workflow end-to-end with a real input (CSV), no CRM integration, priced as Sprint ($499) or Unlimited ($99/mo) against A’s proven reactivation math and failed setter spend.
